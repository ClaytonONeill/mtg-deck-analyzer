# Data model

This page lists the app's domain types in `src/types/index.ts` and shows how each module in `src/store/` maps them to Supabase tables.

Everything here comes from the TypeScript source. It is not the database schema. Column types, constraints, indexes, and row-level security (RLS) policies live in the Supabase project and are not documented here.

## Domain types

All types are exported from `src/types/index.ts` (import path `@/types`).

### `Deck`

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | Generated client-side with `crypto.randomUUID()` (`createNewDeck`). |
| `name` | `string` | |
| `commander` | `ScryfallCard \| null` | |
| `partner` | `ScryfallCard \| null` | Second commander. Cleared by `setCommander`. |
| `colorIdentity` | `string[]` | Commander's identity, merged with the partner's when one is set. |
| `entries` | `DeckEntry[]` | The non-commander cards. |
| `createdAt` | `string` | ISO 8601 timestamp. |
| `updatedAt` | `string` | ISO 8601 timestamp. `deckStore.save` overwrites it with the save time. |
| `objectives` | `Objective[]` | The deck's **Strategy**: 1–2 deck-level themes. Stored as full `Objective` copies, not ids. |
| `versions` | `DeckVersion[]` | Saved versions of the deck. |

### `DeckEntry`

| Field | Type | Notes |
| --- | --- | --- |
| `card` | `ScryfallCard` | Full card object, embedded. |
| `quantity` | `number` | Above 1 only for singleton-exempt cards (basic lands, "any number of cards named" cards). |
| `category` | `CardCategory` | Set by `inferCategory(card)` when the card is added. |
| `objectiveIds` | `string[]` | The card's **Objectives**: ids of `Objective` rows the user applied to this card. |
| `type_line` | `string` (optional) | Not set by `addCardToDeck`. |

`CardCategory` is one of `"Commander"`, `"Creature"`, `"Land"`, `"Instant"`, `"Sorcery"`, `"Enchantment"`, `"Artifact"`, `"Planeswalker"`, `"Other"`.

### `DeckVersion`

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | `crypto.randomUUID()`. |
| `name` | `string` | |
| `note` | `string` | |
| `swaps` | `{ removeCardId: string; addCard: ScryfallCard }[]` | Cards this version takes out (by Scryfall id) and puts in (full card). |
| `objectiveOverrides` | `{ cardId: string; objectiveIds: string[] }[]` | Per-card Objective tags that apply only in this version. |
| `createdAt` | `string` | ISO 8601 timestamp. |

Versions have no table of their own. They are stored inside the `decks.versions` column.

### `Objective`

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | `crypto.randomUUID()`, generated by `objectivesStore.addObjective`. |
| `label` | `string` | |
| `description` | `string` | |
| `color` | `string` | |
| `createdAt` | `string` | ISO 8601 timestamp. |

An `Objective` is referenced in three places:

- `DeckEntry.objectiveIds` and `DeckVersion.objectiveOverrides[].objectiveIds` hold ids.
- `Deck.objectives` (Strategy) and `WishlistEntry.objectives` hold full copies.

`objectivesStore.updateObjective` and `deleteObjective` write only the `objectives` table. They do not touch the copies embedded in `decks` or `wishlist_entries`.

Card Roles (ramp, draw, removal, and so on) are detected from rules text by `detectCardRoles()`. They are never stored, so they are not part of this data model.

| `deckIds` | `string[]` | Ids of the decks this entry is tagged for. |
| `note` | `string` | |

### `PendingSwap`

| Field | Type |
| --- | --- |
| `removeCardName` | `string` |
| `removeCardId` | `string` |
| `addCard` | `ScryfallCard` |

`PendingSwap` is UI state only. It is never written to Supabase directly. `DeckDetailPage` holds a list of pending swaps until they are saved into a `DeckVersion`. `useDeckVersions.ts` declares its own local `PendingSwap` interface with only `removeCardId` and `addCard`.

### `ScryfallCard`

This is the subset of Scryfall's card object that the app types and reads. Cards are stored whole (as JSON) wherever they appear in a deck or wishlist row, so any extra Scryfall fields in the API response are persisted too.

| Field | Type | Notes |
| --- | --- | --- |
| `id` | `string` | Scryfall card id. |
| `name` | `string` | Duplicate (singleton) checks compare by `name`, not `id`. |
| `mana_cost` | `string` | |
| `cmc` | `number` | |
| `type_line` | `string` | |
| `oracle_text` | `string` | |
| `color_identity` | `string[]` | Letters from `W`, `U`, `B`, `R`, `G`. |
| `colors` | `string[]` | |
| `power` | `string` (optional) | |
| `toughness` | `string` (optional) | |
| `legalities` | `Record<string, string>` | |
| `keywords` | `string[]` (optional) | Missing on older saves. |
| `image_uris` | `ScryfallImageUris` (optional) | `small`, `normal`, `large`, optional `art_crop`. |
| `card_faces` | `ScryfallCardFace[]` (optional) | Multi-faced cards. Each face has `name`, `mana_cost`, and optional `type_line`, `oracle_text`, `power`, `toughness`, `image_uris`. |
| `prices` | `ScryfallPrices` (optional) | `usd`, `usd_foil`, `usd_etched`, `eur`, `eur_foil`, `tix`. Each is `string \| null`. |

## Tables

The code uses three tables. Rows are read with `select("*")`. Each insert or upsert sets `user_id` from `supabase.auth.getUser()`. Reads do not filter by `user_id`.

### `decks`

Read and written by `deckStore`. The mapping is inline in `getAll`, `getById`, and `save`.

| Column | Domain field | Read default (when null) |
| --- | --- | --- |
| `id` | `Deck.id` | — |
| `user_id` | — (write only) | — |
| `name` | `Deck.name` | — |
| `commander` | `Deck.commander` | `null` |
| `partner` | `Deck.partner` | `null` |
| `color_identity` | `Deck.colorIdentity` | `[]` |
| `entries` | `Deck.entries` | `[]` |
| `objectives` | `Deck.objectives` | `[]` |
| `versions` | `Deck.versions` | `[]` |
| `created_at` | `Deck.createdAt` | — |
| `updated_at` | `Deck.updatedAt` | — (set to the current time on every save) |

`commander`, `partner`, `entries`, `objectives`, and `versions` hold nested objects (whole cards, entries, and versions) rather than ids or join rows.

### `objectives`

Read and written by `objectivesStore`, through `rowToObjective`.

| Column | Domain field |
| --- | --- |
| `id` | `Objective.id` |
| `user_id` | — (write only) |
| `label` | `Objective.label` |
| `description` | `Objective.description` |
| `color` | `Objective.color` |
| `created_at` | `Objective.createdAt` |

### `wishlist_entries`

Read and written by `wishlistStore`, through `rowToEntry`.

| Column | Domain field | Read default (when null) |
| --- | --- | --- |
| `id` | `WishlistEntry.id` | — |
| `user_id` | — (write only) | — |
| `card` | `WishlistEntry.card` | — |
| `deck_ids` | `WishlistEntry.deckIds` | `[]` |
| `note` | `WishlistEntry.note` | `""` |
| `added_at` | `WishlistEntry.addedAt` | — |
| `objectives` | `WishlistEntry.objectives` | `[]` |

`wishlistStore.add` queries `card->>id`, the Scryfall id inside the `card` JSON, to find an existing entry for the same card.

## Store functions

Each store is a plain object of `async` functions that call Supabase.

The error behaviour is the same in all three stores:

- **Reads degrade.** On a Supabase error they log to `console.error` and return `[]` or `undefined`.
- **Writes throw.** Any Supabase error is thrown. A write that needs the signed-in user throws if there is none.

### `deckStore` (`src/store/deckStore.ts`)

| Function | Kind | Behaviour |
| --- | --- | --- |
| `getAll(): Promise<Deck[]>` | Read | All rows, newest `created_at` first. Returns `[]` on error. |
| `getById(id): Promise<Deck \| undefined>` | Read | One row via `maybeSingle()`. Returns `undefined` when the row is missing or on any error. |
| `save(deck): Promise<void>` | Write | Upserts the whole deck (`onConflict: "id"`), with `updated_at` set to now. Throws `"deckStore.save: no authenticated user"` or `"Failed to save deck"`. |
| `delete(id): Promise<void>` | Write | Deletes by `id`. Throws `"Failed to delete deck"`. |

On `DeckDetailPage`, every deck write goes through `useDeckAutosave`, which calls `deckStore.save`. See [Add a data write](../how-to/dev/add-a-data-write.md).

`deckStore.ts` also exports pure helpers that do not touch Supabase:

| Group | Functions |
| --- | --- |
| Construction | `createNewDeck(name)` |
| Commanders | `setCommander(deck, card)`, `setPartner(deck, card)`, `removePartner(deck)` |
| Strategy | `addStrategicObjective(deck, objective)`, `removeStrategicObjective(deck, objectiveId)` |
| Entries | `addCardToDeck(deck, card)`, `removeCardFromDeck(deck, cardId)` |
| Rules | `isCardLegalForDeck(colorIdentity, card)`, `isSingletonExempt(card)`, `isDuplicateCard(existingCards, card)`, `duplicateCardInDeck(deck, card)`, `findDuplicateCardNames(deck)` |
| Queries | `getDeckCardCount(deck)`, `getAllCardIdsInDeck(deck)` |
| Import/export | `defaultExportFilename(deck, format)`, `buildDeckTextExport(deck)`, `buildDeckExportBlob(deck, format)`, `downloadBlob(blob, filename)`, `importDeckFromFile(file)` |

Every helper that changes a deck returns a new `Deck` and sets `updatedAt` to now. `DeckExportFormat` is `"json" | "xlsx" | "txt"`.

### `objectivesStore` (`src/store/objectivesStore.ts`)

| Function | Kind | Behaviour |
| --- | --- | --- |
| `getAllObjectives(): Promise<Objective[]>` | Read | All rows, newest `created_at` first. Returns `[]` on error. The error log is labelled `deckStore.getAll error:`. |
| `addObjective(objective): Promise<Objective>` | Write | Inserts `label`, `description`, and `color` from the argument. Generates a new `id` and `created_at` and ignores the argument's own values. Returns the inserted row. Throws if no user is signed in or on error. |
| `updateObjective(objectiveId, { label, description }): Promise<Objective>` | Write | Updates `label` and `description` only. Returns the updated row. Throws on error. |
| `deleteObjective(objectiveId): Promise<void>` | Write | Deletes by `id`. Throws on error. |

### `wishlistStore` (`src/store/wishlistStore.ts`)

| Function | Kind | Behaviour |
| --- | --- | --- |
| `getAll(): Promise<WishlistEntry[]>` | Read | All rows, newest `added_at` first. Returns `[]` on error. |
| `getForDeck(deckId): Promise<WishlistEntry[]>` | Read | Rows whose `deck_ids` contains `deckId`. Returns `[]` on error. |
| `add(card, note = ""): Promise<WishlistEntry>` | Write | Returns the existing entry if one matches `card.id`. Otherwise inserts a new entry with empty `deck_ids` and `objectives`. Throws if no user is signed in or on insert error. |
| `remove(entryId): Promise<void>` | Write | Deletes by `id`. Throws on error. |
| `tagDeck(entryId, deckId): Promise<void>` | Write | Reads `deck_ids`, then appends `deckId` if it is not already there. |
| `untagDeck(entryId, deckId): Promise<void>` | Write | Reads `deck_ids`, then writes it back without `deckId`. |
| `updateNote(entryId, note): Promise<void>` | Write | Overwrites `note`. |
| `updateObjectives(entryId, objectives): Promise<void>` | Write | Overwrites `objectives`. |
| `addObjective(entryId, objective): Promise<void>` | Write | Reads `objectives`, then appends `objective` if its `id` is not already there. |
| `removeObjective(entryId, objectiveId): Promise<void>` | Write | Reads `objectives`, then writes it back without that `id`. |

The read-then-write functions (`tagDeck`, `untagDeck`, `addObjective`, `removeObjective`) make two requests, and they throw if either request fails. Nothing locks the row between the read and the write.

`getForDeck`, `updateNote`, and `updateObjectives` have no callers outside `src/store/`. `useWishlist` provides its own `getForDeck`, which filters the entries already loaded in memory.
